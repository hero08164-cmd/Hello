# Typography Video Maker

Independent Android project. Package: `com.bharatcloud.myvideoeditor`.

This is an early prototype with video import/preview, timed text layers and MP4 export. It is not feature-complete or a KineCut clone. Automatic captions, AI tools, background removal, audio mixing and full kinetic typography are not implemented yet.

Build: open GitHub Actions and run **Build Typography Video Maker APK**. Download the artifact only after a successful workflow run.
